# IT Troubleshooting Labs

Hands-on IT support and troubleshooting exercises performed in a controlled virtual lab environment.

These labs are designed to practice the same systematic troubleshooting approach used in help desk, desktop support, and IT support technician roles.

## Labs

### Lab 01 — Basic Network Troubleshooting

**Scenario:** A user reports that their computer cannot access the Internet.

This lab demonstrates a step-by-step troubleshooting process:

* Network interface verification
* IPv4 address identification
* DHCP verification
* Default gateway verification
* Gateway connectivity testing
* Internet connectivity testing
* DNS resolution testing
* Troubleshooting documentation

**Environment:**

* Ubuntu Server ARM64
* UTM virtual machine
* Apple Silicon Mac Mini M1
* Network interface: `enp0s1`

## Purpose

The purpose of these labs is to maintain and demonstrate hands-on IT support skills through practical exercises and documented troubleshooting.

Additional labs will cover Windows, networking, Microsoft 365/Entra ID, PowerShell, and cybersecurity fundamentals.

## Lab Safety

All exercises are performed in a controlled lab environment.

No production credentials, passwords, API keys, or sensitive information should be stored in this repository.
