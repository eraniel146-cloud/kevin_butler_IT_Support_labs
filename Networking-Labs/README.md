# Networking Labs

Practice area for foundational networking and connectivity troubleshooting.

## Topics
- OSI and TCP/IP models
- IPv4 addressing and subnetting
- DNS and DHCP concepts
- LAN/WAN and VPN concepts
- `ipconfig` / `ifconfig`
- `ping`, `tracert` / `traceroute`
- `nslookup` and `dig`
- `netstat` / `ss`
- Basic connectivity troubleshooting workflow

## Lab format
Record the symptom, commands used, output, interpretation, likely cause, corrective action, and verification step.
