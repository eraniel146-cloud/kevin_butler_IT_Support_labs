# Windows & PowerShell Labs

Hands-on practice area for Windows support and PowerShell administration.

## Suggested labs
- Collect system information with PowerShell
- Identify running services and processes
- Review Windows event logs
- Test network connectivity with `ipconfig`, `ping`, `tracert`, and `Test-NetConnection`
- Create, inspect, and manage folders and files
- Document a simulated desktop-support ticket

## Evidence to add
Include command output, screenshots, or short notes showing the problem, the steps taken, and the result. Remove usernames, IP addresses, hostnames, or other sensitive information before publishing.
